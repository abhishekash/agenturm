Opt-in Rust Codex session reader

agenturm-codex-harness is a separately installed Rust process adapter for one explicitly selected Codex rollout JSONL session file. It uses the shared bounded JSONL runtime, versioned process protocol, SHA-pinned executable and host-owned durable admission. The built-in Codex reader stays the default.

Install explicitly

cargo build --locked --release -p agenturm-codex-harness
python examples/rust_codex_harness_plugin/install.py \
  --binary /absolute/path/to/target/release/agenturm-codex-harness \
  --destination /absolute/path/to/codex-plugin \
  --source /absolute/path/to/rollout.jsonl
agenturm serve --plugin-config /absolute/path/to/codex-plugin/plugins.toml

The installer copies and pins a local executable and refuses existing files or symlinked path components. The receiver verifies the artifact and grant before use. Only coarse lifecycle reasons, reported token counters, role, tool category/result and recognized check category/result enter the Store. Prompt, answer, command, path, arguments, output, raw abort reason and model text remain out of admitted facts.

Outcome rules

Completion requires task_complete or an item_completed final-answer phase. Interruption requires task_aborted or turn_aborted. A PR mentioned in prose, an ordinary assistant message, tool result, EOF or silent worker exit never means completion. Conflicting terminal facts at one timestamp become unknown.

Late older-turn facts retain their own turn scope without rewinding the durable current-turn checkpoint. Historical terminal or waiting events become coarse diagnostics rather than changing the current session outcome.

Unmarked outputs cannot be called successful. Modern usage repeats with changed values fail before acknowledgment. Legacy cumulative usage is diagnostic only. Internal codex-auto-review context fails visibly. The durable cursor preserves explicit turn identity and distinguishes detected source rewrites by generation.

This is a metadata-only, partial single-file slice. It does not discover all Codex sessions, retain content, reproduce native traces, support every Codex version or replace the built-in reader automatically. It is POSIX-only and tested on Linux x86_64. No performance gain is asserted. See the validation and parity gaps.
