Install Agenturm

Native app for Apple Silicon Mac and supported Linux. No Python or Rust toolchain required.

Supported systems

  • Apple Silicon (arm64) running macOS 13 or newer.
  • Linux (x86_64 or aarch64) with glibc 2.39 or newer.

Intel Macs and Rosetta are not supported.

Install with curl

curl -fsSL https://www.agenturm.dev/install.sh | bash
agenturm

To upgrade, run the same curl command again. The installer verifies the pinned release and backs up an existing launcher before installation. Its default command directory is ~/.local/bin; add it to PATH if needed. Set AGENTURM_INSTALL_DIR and AGENTURM_BIN_DIR to customize the install locations.

Install with Homebrew

brew install abhishekash/tap/agenturm
agenturm

Upgrade with brew upgrade agenturm.

Start monitoring

Keep your coding agents open and run agenturm in another terminal. Agenturm discovers supported local Codex, Claude Code, OpenCode, Pi, and Kiro records.

Prompt history on Linux

Open an agent and choose Prompts, or press P from the agent list. If the local source has not been enabled, press a at “Enable prompt history”. Choose a request and press Enter or Right to read it. This enables saved user prompts for that source and its sessions; tool payload permissions remain separate.

Close an older running Agenturm process before launching the updated command. Confirm the installed command with agenturm --version; this update reports agenturm 0.3.14.
