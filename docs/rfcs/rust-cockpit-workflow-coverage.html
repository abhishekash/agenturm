Cockpit patch acceptance

The local cockpit candidate opened Agents from the bare executable at 60×18 with empty state. Two fixture files added while the cockpit was open produced durable Pi and Codex sessions. A roster refresh showed both sessions. After quit, another collector opened the same SQLite store and resumed its cursors. The archived inspector also opened a recorded Codex turn through cross-source history and displayed its native completion reason.

The release checks include opening a specific session, reading scoped activity and review, returning to the same selection, and terminal restoration. Linux bundle verifier

The cockpit update adds an Agents roster, source-scoped session Overview, Activity, Review and Usage, and global shortcuts for available evidence. Review acknowledgement applies to the selected evidence version. The global MCP pane covers recorded tool outcomes and operation IDs. Workflow request handling, terminal routing, deep traces and MCP details, general prompt navigation, and cross-session task handoffs remain distinct workflows.
