Agenturm 0.2.1

Released 12 November 2026. A patch release that keeps the Agents view focused on the task rather than the latest steering prompt.

What changed

Task labels keep the first substantive captured request. A session that starts with “Fix refresh token expiry” keeps that identity after “Add cancellation coverage,” “continue,” or “switch model.” Recent activity stays separate on the source line, and the original requests remain available in Prompts. Substantive per-turn trace requests are preserved.

Codex, Claude Code, and Pi retain the identity across reader restarts. Large native files use a bounded identity-only prefix read when startup jumps to recent activity. OpenCode prefers the first substantive request over generated session titles in both supported schemas; bounded reads and a roster-sized cache avoid repeatedly reading unchanged identity text.

Additive metadata carries the initial request into stored session views. Worker scoping, metadata-only capture, and internal-review redaction remain enforced. No database migration or automatic model request is introduced. The existing AI summary action remains on demand.

The package README now explains the developer workflow with current terminal captures, a 37-second captioned walkthrough and transcript, and links to the interactive demo on agenturm.dev.

Upgrade

uv tool upgrade agenturm
agenturm

For a fresh isolated install:

uv tool install agenturm==0.2.1

For pipx, use pipx upgrade agenturm. For a pip-managed environment, use python -m pip install --upgrade agenturm.

Restart Agenturm and any separately running receiver after upgrading. An older receiver cannot recover an initial request it does not provide. Updating the terminal alone only improves the fallback from available activity.

Validation and limits

The application passed all 12 CI jobs, including the 622-test suite on Python 3.11–3.14 (14 optional SDK skips in base environments, exercised separately by integration jobs). Installed-wheel module checks and a persisted-identity smoke passed, alongside native capture, restart, database replacement, scope, privacy, and compact inspector regressions.

Identity collection remains bounded. Missing, deleted, or out-of-window initial requests cannot be reconstructed; Agenturm uses the earliest useful available evidence and then a meaningful runtime-provided task. See task identity and capture limits.

The previously documented long-session memory finding remains open. This patch does not establish memory stability; see the validation report.
