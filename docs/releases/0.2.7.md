# Agenturm 0.2.7

Evidence that is easier to read, without changing what was recorded.

## Clearer inspectors

- Activity messages have a short **Agent message** or **User message** heading instead of repeating a clipped copy of the message above its full content.
- Metadata aligns in label/value columns. Section bodies have a consistent inset, and long values wrap rather than disappearing behind an ellipsis.
- Recognizable narrative Markdown renders emphasis, nested lists, links, fenced code and tables. Tables become labeled records when the reading pane has fewer than 80 content columns. Link destinations remain attached to their labels; Agenturm does not open them automatically.
- Structured JSON retains its hierarchy instead of becoming unrelated peer headings. Code, diffs and literal output retain their relative indentation.

The shared layout covers agent details, Activity, MCP calls, spans, host details, metrics and findings. Review, Workflow, exact-source readers, saved tasks and decisions use the same section rhythm. Usage, Diagnostics, help and export previews rewrap when resized or revealed.

## Original evidence stays original

The readable view does not rewrite stored messages or verify their claims. **c** without a text selection copies the current record, including captured Markdown and link destinations. Original-capture and export previews remain literal. Existing capture-policy checks still apply when source content is cleared or replaced.

Very large or HTML-bearing narrative captures fall back to literal text. Terminal fonts, link handling and clipboard support still depend on your terminal and platform.

## Upgrade

For an isolated tool installation:

```sh
uv tool upgrade agenturm
agenturm
```

For a fresh isolated install: `uv tool install agenturm==0.2.7`.

If you use `uv run agenturm` from a source checkout, update that checkout with `git pull --ff-only`, then restart the app. Upgrading an isolated tool does not update a separate source checkout.
