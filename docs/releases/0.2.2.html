Agenturm 0.2.2

Unpublished candidate, superseded by 0.2.3 after the full CI gate found a branch-ordering regression. No 0.2.2 distributions were published.

A clearer Agents roster, stable task identity, and simpler status labels. This release includes the changes from the unpublished 0.2.1 candidate.

Read the work at a glance

  • In progress, Needs attention, and Ready for review replace the many internal status names in the main roster. The inspector retains the exact lifecycle and process evidence. Unavailable status means a status check, not an invented approval request or completion.
  • Session blocks use whitespace instead of striped bands. The source line keeps runtime, project, and relevant worker counts; recent activity and relationship provenance stay in the inspector.
  • Each hierarchy level indents four cells, including leaves. Source lines align beneath task titles and ancestor guides continue through the spacing. Collapsed branches retain hidden progress and attention counts. A completed parent keeps its own outcome while its children work.
  • Task labels keep the first substantive captured request. Model switches and acknowledgements remain in Prompts without renaming the task. Claude Code local-command caveats, operational envelopes, and local command output are excluded, including recognised truncated caveats in old stored labels. Original captured prompts remain inspectable.

Codex, Claude Code, and Pi retain identity across receiver restarts, with bounded identity-only prefix reads for large files. OpenCode prefers the first substantive request over generated titles and bounds identity reads and caching. Exact worker scope, metadata-only capture, and internal-review redaction remain enforced. No database migration or automatic provider request is introduced; optional AI summaries remain on demand.

The updated README explains the development workflow with terminal captures, a 37-second captioned walkthrough and transcript, and the interactive website demo. Existing screenshots and video retain their truthful capture-version labels.

Upgrade

uv tool upgrade agenturm
agenturm

For a fresh isolated install: uv tool install agenturm==0.2.2. For pipx, use pipx upgrade agenturm; for a pip-managed environment, python -m pip install --upgrade agenturm.

Restart Agenturm and any separately running receiver. A fresh receiver can rediscover native initial requests with the corrected rules. An older receiver cannot supply identity it never captured.

Evidence and limits

Peer review covered status truthfulness, notification isolation, Claude command/output permutations, hierarchy alignment, keyboard navigation, and compact layouts. Regression coverage checks raw-prompt preservation, restarts, bounded reads, privacy, status transitions, reviewed completions, and selection across refresh and resize. Release artifacts are checked in isolated environments before publication.

Needs attention includes status that cannot be confirmed. The inspector says whether a reply is actually required or collection needs inspection. This display category does not create a workflow incident or desktop alert. Ready for review means agent-reported completion; it does not certify tests or the current worktree.

Identity collection remains bounded. Deleted, missing, or out-of-window requests cannot be reconstructed. See capture limits. The previously documented long-session memory finding remains open; see the validation report.
