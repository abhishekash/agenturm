Agenturm 0.2.6

Find the agent that needs you—and see why.

Attention with a clear next step

  • Click the attention count or press ! to show the affected agents, including children hidden in collapsed branches. The action clears the Agents search and individual session scope so they do not hide a counted item.
  • Rows name the reason: Needs approval, Needs reply, Run failed, Interrupted, Incomplete, Check progress, or Check status.
  • The inspector starts with Why attention and Next step, pointing to the agent terminal, recorded Activity, a linked trace, or collection details as appropriate. An uncertain wait is not presented as a request for your reply.
  • Attention is also available in the Show selector and command palette. a Reset returns to Today. Typing ! in a search field remains ordinary text.

A responsive opening view

The interactive cockpit opens before checking or starting its receiver, so you can navigate, resize, or quit while receiver setup runs. Available agents stay visible while older history loads. History limitations are labeled separately from the connection status, with read failures, freshness, and source coverage available under d Details alongside Refresh now.

Connection and authentication failures remain explicit. Missing observations remain unknown rather than becoming confirmed zero counts. The noninteractive --once command keeps its complete-snapshot checks.

Upgrade

uv tool upgrade agenturm
agenturm

For a fresh isolated install: uv tool install agenturm==0.2.6. Restart the cockpit and any separately running receiver after upgrading.

If you run from a source checkout with uv run agenturm, update that checkout with git pull --ff-only before running it again. Upgrading an isolated tool does not update a separate checkout.
