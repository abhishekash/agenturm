Agenturm 0.2.8

A simpler default workspace, stable navigation and clearer interruption evidence.

Less clutter

  • Keep Agents, Activity, MCP Calls and Traces in the main navigation. Host, Metrics and Findings are under More, with all seven numeric shortcuts retained.
  • Use a compact header and five everyday footer actions. Remove repeated counts, sort hints and duplicate command previews; hide Errors 0 unless its filter is selected.
  • Keep Overview focused on useful recorded work and actionable explanations. Detailed status evidence and hierarchy remain in Details; full recorded history remains in Activity. Startup uncertainty, errors and empty/search feedback stay visible.

At 150×40 the header, navigation and toolbar occupy four rows instead of eight. The interface retains its narrow layout and minimum supported size of 60×18.

Stable views and clearer status

  • Keep the global header and navigation in place when opening an inspector or changing views, with consistent mouse and keyboard transitions.
  • Label the session scope Session: All. Clearing session scope preserves independent time, search and error filters.
  • Preserve recorded interruption reasons and exact turn identity. A later completion or resumed turn takes precedence over an older interruption; unrelated failed commands do not become the interruption cause.
  • Keep linked Activity and trace inspection scoped to the selected execution. Missing reasons remain explicitly unknown: a pull request or a failed check alone does not establish the lifecycle outcome.

The repository also adds live adoption and compatibility badges. This release does not add usage telemetry or the proposed harness-adapter architecture.

Upgrade

uv tool upgrade agenturm
agenturm

For a fresh isolated install: uv tool install agenturm==0.2.8.

Restart the TUI and any separately running receiver after upgrading so both use the updated lifecycle handling. For a source checkout, run git pull --ff-only and restart; upgrading an isolated tool does not update a separate checkout.
