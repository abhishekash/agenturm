# Agenturm 0.2.5

Find a recorded approval or reply request, see its owner and reason, and use the supported terminal-return action from Workflow. Seen is an acknowledgement, not a reply or resolution; source-backed resolution remains distinct. Copying a native resume command is a separate action and does not run it.

Review now prioritizes the latest strictly ordered comparable check attempt while retaining the earlier evidence. Continuity drafts identify request text as the latest captured request. When Workflow is empty, first-run guidance distinguishes missing discovery, delayed collection, limited capture, and no recorded requests in the available coverage.

## Upgrade

```sh
uv tool upgrade agenturm
agenturm
```

For a fresh isolated install: `uv tool install agenturm==0.2.5`. Restart Agenturm and any separately running receiver.

Agenturm observes local coding-agent activity and recorded evidence. Replies and approvals remain in the agent’s native terminal; terminal return is available only where a supported live target can be verified.
