# Agenturm Rust 0.3.15

Delegated agents now start collapsed in the task roster. Expand them when you need their individual rows. Project groups sort by their highest recorded status, then by latest update, so a working delegated agent brings its project forward. In an ungrouped roster, working tasks sort ahead of other statuses and then by update time.

The roster preserves explicit expand/collapse choices and selected task identity across history refreshes.

Restart Agenturm after installation to load the updated interface.
