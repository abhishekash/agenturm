# Agenturm 0.2.0

Released 12 November 2026. A clearer view of local agents, their recorded work and the tasks you want to carry forward.

## What changed

- **Understand active work.** Agents have clearer row separation, human-readable task descriptions and organized subagents. Working and attention states take priority, while missing or stale capture remains explicit.
- **Read the conversation.** The expanded inspector separates Overview, Prompts and Details. Arrow keys choose requests; Enter/Right reads; Left returns to request navigation. Persistent F1 help and contextual hints explain the controls. Focus and reading positions survive updates and resize, including compact 60×18 layouts.
- **Review recorded progress.** Scoped, on-demand review connects captured checks, edits and errors with bounded history and frozen copy/export. Agent-reported completion is separate from verified checks and the current worktree.
- **Handle attention deliberately.** The workflow inbox tracks waiting requests, failures and reported completion. Local acknowledgements and opt-in notification delivery claims survive restarts; seen requests remain pending until fresh evidence resolves them.
- **Keep task continuity.** Saved tasks support structured briefs, versioned decisions, explicit evidence links, handoff previews and continuity CLI commands. Receiver namespaces remain separate. Existing notes are preserved, and an explicit SQLite backup command is available before migration.
- **Recover and exit correctly.** Available live agents remain visible when stored reads are delayed. External interrupts, termination during startup and UI failures restore the terminal and return meaningful exit statuses. Lost prompt focus returns to navigation.

The experimental Rust ingestion change is reverted. This release uses the Python implementation.

## Upgrade

```sh
uv tool upgrade agenturm
agenturm
```

If you installed with pipx, use `pipx upgrade agenturm`. For a pip-managed environment, use `python -m pip install --upgrade agenturm`.

For a fresh isolated install:

```sh
uv tool install agenturm==0.2.0
```

Restart Agenturm and any separately running receiver after upgrading. Optional SDK integration extras remain available.

## Validation and known limits

The application passed all 12 CI jobs, including its 610-test discovery suite across Python 3.11–3.14 (14 optional SDK skips in base environments, exercised separately by integration jobs). Installed-wheel, minimum-Textual, real tmux and loopback SSH keyboard checks also passed. A 20-minute synthetic run completed 400 cycles and recovered from both planned receiver replacements; a final-source smoke verified the stronger evidence and cleanup assertions.

**Memory stability is still under investigation.** RSS rose from about 70 to 125 MiB during the mixed headless soak despite bounded review caches and stable sampled file descriptors. This is not a claim of multi-hour stability. The tests also do not establish WAN resilience or every terminal emulator's behavior.

See the [full validation report](https://github.com/abhishekash/agenturm/blob/v0.2.0/docs/rigorous-validation.md) for exact source provenance and measurements, and the [keyboard guide](https://github.com/abhishekash/agenturm/blob/v0.2.0/docs/keyboard-navigation.md) for navigation.
