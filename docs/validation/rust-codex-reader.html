Native Codex stays the default. This is partial metadata evidence, not a full migration or speed claim.

Evidence and outcomes

The adapter emits only content-free role, tool, check, modern usage and lifecycle facts. It hashes tool call IDs before the child pipe. The installed 0.167.1-shaped fixture matches native Codex on explicit completion and verifies usage, check outcomes, turn drilldown, partial coverage and exclusion of private text.

task_complete and final-answer phase report completed with distinct reason codes; task_aborted and turn_aborted report interrupted. PR prose remains an ordinary message. Same-time conflicting outcomes become unknown/ambiguous_lifecycle. Unmarked tool outputs do not become successful. Changed repeats of one usage response fail before acknowledgment instead of adding counters twice.

A late fact carrying an older explicit turn ID keeps its own turn scope without rewinding the durable current-turn checkpoint. Only task-start and new user-message boundaries change that checkpoint. Historical terminal or waiting events become coarse diagnostics rather than overwriting the current session outcome. Installed restart tests cover this case.

Whole-line admission, restart turn checkpoint, checked header/tail and gap generation use the shared runtime. Malformed evidence and internal auto-review context fail visibly. The Python receiver owns every policy, lease, commit, retention, projection and database write.
