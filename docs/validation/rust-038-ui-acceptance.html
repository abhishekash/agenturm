Status: opt-in candidate, 23 November 2026. Runtime code is frozen at 1df22a4; later changes update documentation and acceptance fixtures only. The default Rust cutover remains gated. Comparative performance benchmarks are deferred.

Implemented behavior

The first screen follows the user's command-center reference in Agenturm's colors: a full-width task table, project headings and counts, All / Needs you / Working / Ready / Inactive filters, explicit unknown counts, and selectable Show more. G cycles project, source and ungrouped views. Enter opens the exact selected inspector; Escape restores its group, filter and source/session. Compact help exposes every control at 60×18.

Task titles use unambiguous exact saved task links or retained structural facts. Project paths use an explicit operator-saved Git root linked at session level to the current local history. The UI labels this Operator task workspace. Invalid, conflicting, archived, worker/turn-only and foreign history candidates remain unavailable. Notes, diffs, prompts and process cwd are outside this projection.

The candidate integrates Python keyboard navigation, selectable MCP and Operations tables, and recorded Activity, Traces, Usage, Findings and Host inspectors. Ctrl+F investigates retained failures or grant-verified source evidence. Search, More and source opening pin logical history identity and read snapshot; local source proof also checks the held writer's current path. X acknowledges one exact current pending request, with a chooser for ambiguity; native lifecycle state remains intact and new revisions can alert again. Authenticated Python receiver attachment supports v for captured internal reviews. Native capture reports its current limitation.

z switches the same granted prompt between Readable and original captured layout, preserving newline/tab layout and independent scroll positions. It does not extend the 25-second display lifetime. Escape, quit, interrupt and expiry redact the modal before acknowledging the private delivery fence. c requests terminal clipboard copy of bounded loaded metadata; x writes that metadata as Markdown, HTML and JSON into a new private directory. These exports exclude private modal bodies, never overwrite a destination, and are explicitly distinct from evidence receipts.

Remaining acceptance

This is not a claim of complete Python UI parity. The user-selected command center intentionally replaces the initial split inspector. Remaining UI work includes configured-but-idle MCP inventory and per-call related traces; generic OTLP metric point/history/exemplar browsing and the seven-day usage chart; grouped/generated Findings with occurrence counts; per-process project labels; and native internal approval review capture. Missing native producer project metadata remains explicitly unavailable without an operator task link.

The execution plan also retains real Kiro transcript qualification, supported production connector endpoint evidence, and additional platform qualification. No production connector delivery is authorized by these local fixtures. These requirements are not retired. See the execution plan and workflow inventory.
