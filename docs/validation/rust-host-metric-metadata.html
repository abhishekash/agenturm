Metrics

Schema 21 adds a separately validated public metric-description companion and index/format marker. Existing point IDs, payloads, series keys, receipts and private grants are not rewritten. A descriptor must be anchored to an admitted point in the same batch and source. Descriptions are bounded to 512 bytes and unsafe or ambiguous text is omitted without discarding valid metric points.

Catalog queries search name, service, kind, unit, scope, source and description before pagination. Source authorization is applied before grouping and limits. The bounded literal query is at most 256 bytes and uses ASCII-insensitive matching. Search, source filter and read snapshot bind the catalog cursor. Existing point wire format/cursors are unchanged; older source-scoped catalog cursors require a fresh first page.

The frozen app passed authenticated JSON/protobuf HTTP ingestion, auth denial, replay, description-only admission, revision and unsafe-text omission. All seven old point rows retained identical IDs, serialized values, digests and receipt sequences. Unit/store checks include schema 20-to-21 compatibility.

Recorded Host inventory

The local Linux writer records a bounded validated hostname and explicit Linux platform when available. Older/remote records without those fields remain unreported. The reader never infers the remote OS from its own host.

Host inventory selects the latest authorized sample per source before limiting results. A remote H reads that inventory without probing the viewer's process filesystem or requesting local capture. Multiple/partial streams open a Recorded host streams chooser rather than selecting an arbitrary source. Refresh keeps inventory mode and exact selected source through reordering. Process drilldown shows recorded source, timestamp and age, and Escape returns to the same stream. Host chronology remains a separate mode.

The exact app and service passed the updated separate-UID Linux KVM fixture: opt-in GET/typed POST, hidden-source exclusion, more than 64 records for one source, multiple streams, metadata/grant denial, and restored binding fences. At all three terminal sizes, a newer sample was published for the previously older selected stream; current settled terminal cells verified refreshed time, exact source/process drilldown and selection return. Collector and reader used different identities; the reader did not reacquire a local sample.

A stale typed history POST returns HTTP 200 with Err(snapshot_replaced). A metadata GET with a stale binding header returns HTTP 409. The fixture was corrected to assert those distinct existing protocol contracts.

python3 scripts/validate_rust_metric_catalog.py --app /path/to/bin/agenturm
