Rust relationship and Activity domain parity

The pure agenturm-domain-reducer fixture now has a version 2 contract for parent relationships and content-free message, tool, and check Activity. Python Store remains the only live database writer and projection authority. No speed claim is made.

Contract

Version 1 input and output are unchanged. Version 2 requires a plugin ID and accepts relationship, message, tool, check, and diagnostic rows with optional native worker, turn, and operation IDs. The reducer validates typed metadata and admitted identity rules, uses the highest revision of each event, rejects kind or identity changes, and emits relationship fields and bounded Activity facts. Diagnostics may update last-record time but do not create Activity.

Python’s relationship rules are reproduced: a unique newest parent is confirmed only when present in the same current source; missing parents are unresolved, equal-time conflicting claims are conflicted, and cycles or self-links are invalid. Retention invalidation clears parent and usage projection and suppresses Activity. Facts contain typed role, category, result, and opaque derived IDs, without prompts, commands, paths, tool output, or free text.

The CLI is read-only and has no policy, lease, database, source-reader, or network authority. Live Rust storage cutover still requires snapshot fencing and the full durability and query gates.

Verification

The version 2 golden corpus has three valid and ten invalid cases. Installed CLI tests validate each valid row through Python wire and metadata admission, insert it into a disposable Store, run production project_source, and compare every persisted session and Activity payload. They cover relationship resolution, corrections, Activity correlation, retention, diagnostics, malformed metadata, and revision identity. Version 1 tests remain in the gate.

cargo fmt --all -- --check

 cargo build --locked -p agenturm-domain-reducer
 AGENTURM_RUST_REDUCER_BIN=target/debug/agenturm-domain-reducer \
   python -m unittest tests.test_rust_domain_reducer tests.test_rust_domain_reducer_v2 -v

These tests compare an isolated fixture. They do not certify live Rust projection or a performance gain.
