What changed

Activity, Operations and MCP

  • operation_table.rs: the inventory is now one row per exact server name. Configuration and loaded calls join by the recorded name; states distinguish disabled, idle, observed + configured and observed-only.
  • Operations panes own a bounded / filter. Every query word must match a recorded field; Esc clears, Enter applies, and older/newer pages inherit the committed filter.
  • The operation detail always shows Server, Result, Latency and Worker. Missing values read Unreported; a missing worker reads Unreported (main session or not recorded); the exact source / event rN MCP call is shown when typed evidence carries it.
  • evidence_view.rs: page context precedes the selected row, empty rows say so, and truncation hints distinguish Enter to read the full detail from widen the terminal.

Findings and diagnostics copy

  • findings.rs: the summary reports groups, exact occurrences and examined observations separately.
  • Group caption names source, signal, occurrence count and the exact-evidence route.
  • Occurrence detail adds N of M, kind, severity, scope, source, event, revision, snapshot and a Source route line.
  • Routes derive from typed FindingSource variants and an absent source is explicit, never silent.

Metrics and Usage

  • metric_history.rs: Home/End select first/last in the catalog and points; the same keys scroll series, point and exemplar detail.
  • usage_chart.rs: v toggles a seven-day list. Compact rows use —, †, *, ‡ with a legend; wide rows spell out coverage.
  • Export scope records chart or list; contextual help names v, Home/End and retained-page keys.

Host and history search

  • host.rs: recorded pages say not live; source, viewer-clock age and recorded Unix timestamp are always shown; hostname appears where it fits.
  • Process history reports whether the exact source/boot/PID/start is present in the newest loaded sample, or exited or unreadable.
  • investigation.rs: bounded four-page back stack, PgUp/PgDn, page number, page-local and end-of-scope disclosure; mode/scope/query edits reset the stack; private queries persist while paging.
  • loaded_view.rs: a selected-row export helper and explicit row counts; escaping and limits unchanged.

Remaining gaps and ownership

  1. Activity page-local filter and prompt-only view. The Activity body is an EvidenceTable in the shared UiModel; there is no per-table filter field and lib.rs owns evidence_key. Needs hook 1.
  2. Trace tree/list navigation, parent/child focus and linked traversal. Trace rows are built and drawn by workspace.rs and session_evidence/table.rs, outside this lane. Detail already carries parent span, target source, status and duration.
  3. Generic Operations related evidence. The shell only accepts t when the operation table is_mcp(), although an Operations row can carry the same typed mcp_event. The detail line now names the exact call; the key remains shell-gated.
  4. Selection-scoped copy/export. workspace/view_io.rs still exports pane metadata. LoadedView::selected_evidence is ready for the shell.
  5. MCP aggregate metric calls. Python shows aggregate metric-only MCP calls (for example Cursor). Rust has no typed fact for that cohort, so the inventory shows loaded-call counts only and says so. Provider payload viewing stays behind FD2 grants.
  6. Session-scoped Metrics. MetricBrowser::scoped and source-filtered queries exist, but the app starts unscoped and there is no session Metrics view.
  7. Diagnostics, health, reconnect and receiver-retry copy. These surfaces are not in this lane's files. Findings retry/policy text is likewise not a Finding action.
  8. Activity worker attribution. Activity details are built by session_evidence/table.rs; an absent worker is omitted there. Operations now state it explicitly.

Pluggable architecture and seam implications

Kept typed and provider-neutral

  • Inventory: joined only by typed ConfiguredMcpServer.name and OperationRow.server; enabled comes from the explicit configuration reader. Counts stay page-local.
  • Findings: routes are FindingSource::{Command, Telemetry, Log, Evaluation}; the UI names the route but never opens a payload itself.
  • Usage: arithmetic uses UsageDay, UsageTotals, CombinedUsageTotals and UsageCurrencyTotal; coverage comes from typed partial/cutoff/truncation flags.
  • Host: current vs recorded uses CurrentHostSample.recorded_source and exact HostSample boot/PID/start identity. Recorded evidence never claims liveness.
  • Investigation: every request keeps typed history identity, snapshot, cursor and owner scope; the app remains the grant and scope authority.

Still typed-fact gaps

  • Aggregate metric-only MCP calls need an FD2 retained fact; they are not inferred from provider names.
  • Provider-specific MCP payload reasons remain behind FD2 proof and a valid grant.
  • Session-scoped metrics need an app/shared routing change, not a UI guess.
  • No kernel port, supervisor, adapter or plugin-host change was needed in this lane.

Acceptance journeys

  • MCP. 3 → i for idle/disabled/observed states, origin, page calls and errors. Esc, f cycles server filters, /query + Enter searches the retained scope, Enter inspects, t follows the linked trace, Esc restores the same server/query/call.
  • Operations. /worker + Enter filters the loaded page; Enter inspects Result/Worker/Trace (Unreported where absent); Esc clears; [/] keeps the same filter.
  • Metrics. 6 → /description + Enter, Home/End, [/], Enter points, e exemplars, Enter exact span; three Escs return to the same series and snapshot.
  • Usage. Open Usage → v list, s cohorts, t counters, n totals, C cost currency. Check Unreported, †, *, ‡ at 60×18 and with NO_COLOR=1.
  • Findings. 7 → Enter occurrences → Enter detail; verify N of M, scope, source and source route; s opens the granted source; Esc returns to the same occurrence.
  • Host. 5 or H → / search; open a recorded sample → process → history; verify not live, source/age and Latest loaded sample. Esc returns through the same process.
  • History search. Ctrl+F → mode → query → Enter; PgDn shows Page 2 and PgUp previous; PgUp restores the prior page and query; Esc closes.
  • Copy/export. c requests an OSC 52 write and reports terminal support; x opens the destination form and writes MD/HTML/JSON. Until hook 3, the document is the loaded page.
