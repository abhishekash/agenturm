Architecture and acceptance boundaries

The shell must consume provider-neutral typed facts and preserve source, session, worker, turn, snapshot and version identity. Private readers retain the existing grant, active-display, redraw-before-acknowledgement and timeout fences. Missing worker proof is unavailability, not permission to relabel main-session content. Copy/export must identify the actual selected scope.

Remaining qualification includes the exact installed binary, the tagged Python 0.2.8 oracle, comparable fixtures at 120×32, 80×24 and 60×18, private reader revocation, nested navigation and terminal restoration. Mouse parity, unsupported provider capabilities and intentional disclosure differences cannot be promoted to accepted parity by passing unit tests.
