Internal Pi exact text read gate

Recorded 20 November 2026. observatory.plugin_pi_content_read.read_exact_pi_user_text is an internal receiver primitive for one selected plugin Activity ID. It returns either Available(redacted_text, proof) or Unavailable(reason). No HTTP, TUI, copy, or export route calls it. Metadata-only capture remains the default.

The reader takes the root only from the Store's active PluginSupervisor registry. It requires an explicit Pi directory configuration with the content grant, a matching artifact generation and configuration fingerprint, enabled capture, a current projection, the exact selected Activity and user-message evidence at revision zero, a matching content row and member owner, and no source gap or retention invalidation. A normal restart may rotate the active lease while retaining content under the same configuration; the returned proof records the current lease.

Because the content table stores a member hash rather than a path, the receiver discovers the member under the configured root without following symlinks. Discovery stops at 48 JSONL files, 256 directories, 4,096 entries, and depth six. It reopens the member without following links and verifies root and file identity, the canonical initial generation, an at most 8 MiB prefix, header identity, exact row bytes and hash, time, role, session, turn, native event identity, and redaction equality. It rereads the selected Store rows, policy, lease, and projection, repeats the full file proof, and checks the Store again. Any mismatch returns an unavailable reason without raw JSONL text or paths. The Store writer lock is never held during source I/O.

The proof is a point-in-time result. A future delivery surface must recheck immediately before display or export and independently settle storage and UI sanitization. This slice does not claim complete native Pi Review parity or a performance improvement.

The read suite covers redaction, empty text, normal lease restart, revocation during proof, pending projection, source gap, missing and symlinked members, a same-inode rewrite, a pathname replacement after file proof, forged Activity payload, and supervisor detachment.
