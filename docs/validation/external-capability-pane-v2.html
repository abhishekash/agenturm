Installable observational capability pane

Recorded 20 November 2026. A second, independently installed process contributes an Action observations pane beside Prompt signals. The existing TUI pane registry renders both. Neither starts by default, and the Prompt signals schema-v1 descriptor and process frames remain unchanged.

Install and activate

python examples/action_observations_process/install.py --destination /absolute/private/actions
python examples/prompt_signals_process/install.py --destination /absolute/private/prompts
agenturm cockpit \
  --capability-config /absolute/private/prompts/capability.json \
  --capability-config /absolute/private/actions/capability.json

The installer writes a SHA-256-pinned executable, manifest and descriptor into a new private directory. The manifest declares capability-adapter/1, requires pane-model/1, and requests the explicit scoped-aggregate-read grant. Bad descriptors fail the explicit startup before a child launches. A later failure of one admitted process makes only its pane unavailable.

Closed schema-v2 model

Schema v2 declares one to six unique rows. Each row selects a known host fact—scoped events, recorded user messages, recorded shell actions, or first-shell delay—or an integer ratio between count fields. The host generates labels, values, coverage and summary from its own facts and accepts the child model only if state, row order, cells, summary and detail match exactly. The child cannot add arbitrary text or an unsupported score.

Ratios use integer half-up rounding to two decimals. A zero denominator is unavailable. “Shell actions / user messages” describes counts in a bounded recent Activity window. It is not a measure of efficacy, quality, causality, productivity or a complete session. Partial coverage is explicit. The compact pane uses two columns and puts coverage once in its summary.

{"schema":2,"pane":{"id":"action-observations","title":"Action observations",
  "columns":[["Signal",34,2],["Observed",12,0]]},
 "model":{"rows":[
   {"key":"users","value":{"fact":"user_messages"}},
   {"key":"actions-per-user","value":{"ratio":["shell_actions","user_messages"]}}]}}

The complete descriptor also names an absolute manifest and the scoped-aggregate-read grant. Columns use the fixed semantic headings Signal, Observed and optionally Coverage. Widths and priorities are bounded, with declared widths totaling at most 54 cells.

Policy and limits

An exact service, session and canonical agent need affirmative capture policy. The receiver gate checks the same receiver and scope before and after a bounded Activity request. The reader rejects more than the requested 200 rows or a non-object event. Only aggregate counts and a coarse elapsed time cross the child pipe; no prompt, command, output, path or source identity does. Revocation clears a warm model on the next pane query. The existing 250 ms cached approval is not an atomic retraction of already displayed text.

This extension covers formulas over current host-owned facts. New fact domains, arbitrary calculations, production third-party SDK guarantees and OS-level sandboxing remain open. The fixture is POSIX-only and runs as the installing user.
