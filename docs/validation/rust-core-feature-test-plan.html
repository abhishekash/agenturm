CF6 — combined deduplicated usage totals

Implemented with the FD3 combined slice. The combined per-UTC-day projection excludes reports whose overlap is established through exact (target source, session) identity and counts the exclusions instead of summing them: native reports are excluded when same-day usage-bearing telemetry claims their exact source and session, and attributed telemetry rows are excluded when same-day native reports exist for the claimed identity. Unattributed telemetry carries no identity link and therefore contributes; that boundary is disclosed, not inferred away. CF7 — cross-host terminal routing

Implemented with the FD4 routing slice. An attached native cockpit accepts an explicit operator-authored --route-file (one command word per line, for example ssh and user@receiver-host); the legacy Python receiver protocol rejects it. l verifies the exact current request, then runs three fixed, read-only, bounded probes through the route: a remote /proc snapshot whose matching processes are proved by exact byte comparison of the resume command tail (NUL-count, basename and length all checked), the tmux pane inventory, and a pane-process re-verification.
