Native state context adapter hook

Recorded 20 November 2026.

Change

The generic Session.observe_state asks an optional trusted adapter hook for working directory and Git context. Codex returns its nested payload; other adapters continue to use the top-level row. The collector no longer checks whether the runtime is Codex for this context.

Boundary

Lifecycle results, storage authority, capture policy, the process plugin contract and external adapter permissions are unchanged. With detail capture disabled, the host publishes the project name and withholds the full working directory and branch. This is a trusted native adapter hook, not an external plugin API.

Verification and limits

Installed tests cover Codex, Claude Code, Pi, Kiro and an injected adapter, plus native session, lifecycle, Activity, Review, schema, Kiro and reader-registry regressions. This removes one collector branch; it does not establish full native parity, Rust storage authority or a performance gain.
