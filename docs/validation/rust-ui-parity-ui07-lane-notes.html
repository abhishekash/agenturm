Concrete fixes

Appearance

An undersized active picker no longer disappears. A cleared resize notice puts Escape first. Every selected theme has a › marker and semantic bold/selection style, independent of color.

Save errors keep cancel/retry visible before a separate clipped error line. Preview/cancel, Space retry/apply, reload and Unix 0600 persistence have new tests.

Palette and session chooser

The two detail rows now show the selected reason instead of wrapping a duplicate long title over it. Truncation has an ellipsis. Disabled rows explicitly say [Unavailable].

Labels clip by cells without splitting graphemes; controls are escaped; group labels yield to subjects. Search keeps its editing suffix/cursor visible. Session counts exclude only the explicit “All sessions” entry.

Help

Scrolling and rendering now use the same inner width/height. End reaches the real last content row. Headings and body wrap by grapheme; controls are escaped.

Resize keeps the logical line/display-byte anchor. Too-small fallback leaves reading state intact. Skipping in usize avoids a u16 scroll wrap.

Too-small and monochrome

All owned fallback frames clear old content and lead with Esc back · resize. Query, selection and theme preview are not silently canceled.

Existing NO_COLOR reverse/bold selection remains; text markers communicate selected and unavailable states. No environment mutation is used in tests.
