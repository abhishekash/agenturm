Contrast observations and remaining visual findings

Static sRGB contrast arithmetic gives minimum essential text/background ratios of 12.87, 14.61, 13.68, 13.87 and 10.50 for the five themes respectively; selected text/background minima are 11.28, 13.76, 11.97, 9.71 and 7.17. Overlay muted text on surface and status colors on surface exceed 4.5:1. These are RGB calculations, not terminal-emulator or ANSI-fallback measurements.

Finding: the unchanged tagged Solarized muted on panel pair is 4.23:1, below the essential-text 4.5:1 target. Owned muted hints/counts use surface; search text uses text on panel. Other screen owners must audit uses of muted-on-panel or approve a semantic fallback/color change. This lane does not claim full-theme contrast qualification. NO_COLOR delegates default contrast to the terminal and preserves structure; it does not force black/white colors.

Other findings are reported without editing their owners' files:

  1. Full-screen compact layout/floor: lib.rs, evidence_view.rs and shared workbench/shell modules retain their own floor/layout policies. Component fixes do not establish one active pane at 60×18 or a coherent global floor.
  2. Global character wrapping: lib.rs::wrap_display_width still iterates characters, not graphemes. Only these overlays now use theme::wrap_cells; other evidence/detail callers still require CJK/combining/emoji audit.
  3. Long palette values: labels/reasons explicitly disclose clipping, but there is no scrollable full-label/detail reader in the palette. The selected session's inspector remains the intended full-value route. Arbitrarily long disabled reasons/identities need explicit acceptance or a shared detail seam.
  4. Focus/overlay integration: help-over-editor/chooser, F2 theme dispatch, focus restoration after close, private-content fences and prompt reflow are shell-owned. No integrated key-delivery or prompt-reader journey was run.
  5. State matrix: this patch covers overlay populated, empty, no-match, unavailable, save-error/retry and too-small states. Startup, async loading, partial/stale/disconnected, permission revocation, refresh safety and cached permitted evidence need full-screen owner/UI-Q runs. It does not fabricate these states inside data-only overlays.
  6. Terminal restoration: quit, interrupt, failed load and supported handoff need real PTY termios checks, including private-frame clearing/ACK. This lane does not own terminal lifecycle and did not run them.
