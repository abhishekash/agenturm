Scope and next gate

This is a disposable two-UID Linux fixture. It covers one pinned release, not every supported old binary or a production canonical Rust database. A cutover still needs old-process shutdown before backup, a protected new service path, complete mutation routing, synchronized backup, crash recovery, and forward-only authority after Rust's first durable write. No performance gain is claimed.
