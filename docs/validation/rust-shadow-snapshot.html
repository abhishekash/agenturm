Fenced read-only Rust domain snapshot

Recorded 20 November 2026. This checkpoint reads one policy-current plugin source from the Python Store in a single SQLite read transaction and makes a version 2 fixture for the pure Rust domain reducer. It also captures the published session and Activity rows from that same snapshot. The Store remains the only writer and live projection authority.

observatory.rust_shadow_snapshot.capture(store, source_id) returns no fixture while capture is disabled or projection is pending. It requires the projection cursor to match the source's dirty sequence and policy epoch, checks the receiver identity, and enforces the Rust reducer's 50,000-evidence, 2,000-session and 16 MiB input bounds. Aggregate SQL byte counts reject evidence or Activity payloads above 8 MiB each before materializing their rows. Every stored payload must pass the host's content-free metadata rules again. Persisted Activity must match freshly derived content-free Activity from the admitted rows before it can become a comparison oracle. The function does not invoke a child or expose prompt, command, path or tool-output text.

The returned revision includes receiver, lease, policy, dirty sequence, capture and projection fields. A caller checks current(store, snapshot) before and after an independently run reducer; any policy change, revocation, admission or projection update makes the old result unusable. The read transaction closes before CPU reduction. There is no dual writer, database migration, automatic shadow process or Rust storage cutover.

The installed test commits lifecycle, usage, relationship, message, tool and check facts through the normal Store admission path, projects them, captures the snapshot, runs the built Rust CLI, and compares all session and Activity output. Separate tests cover pending projection, admission change, capture revocation, unknown source, corrupt stored metadata and corrupt published Activity. This is an isolated compatibility proof. Full storage/query parity, live process supervision, broader harness conformance and rollback remain open.
