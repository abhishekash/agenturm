Narrow eligibility and fallback

Only exact built-in dictionaries with an operation_v1 role and built-in string detail qualify. Explicit mutable evidence, compact references, mutable/non-string details and unusual result values use the original path. Error-reference processing preflights every row before any normalization. Every source-bearing event must have a passed, nonconflicting terminal result, no raw failure and no recorded exit code one. Findings also falls back for exit one in every domain, incomplete/raw failures or conflicting results.

The retained scan uses the original stable reverse timestamp ordering, without an identity tie breaker or occurrence deduplication. It fetches full facts from each original event/context before trace and receiver wrapper overrides. Full facts, exact key and positive timestamp must qualify; the original second compacting operation remains. Missing keys are skipped until twenty distinct keys or all candidates are exhausted. Output clipping and redaction do not add new success-exclusion rules. Genuine retained full-fact/context exceptions propagate; only pure gate uncertainty falls back.
