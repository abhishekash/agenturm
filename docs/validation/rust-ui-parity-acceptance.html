Important discoveries during qualification

  • The original shell compiled but failed navigation tests. Several additional audit findings concerned private redaction, wrong evidence identity and form reconciliation. See the preserved audit and the integration note's finding-to-regression table.
  • An actual terminal run found that returning to Agents during a pending destination read could be ignored. The key now supersedes that navigation, and the late response is discarded. A regression exercises the race.
  • The smoke harness initially accepted the word Activity in a navigation strip rather than waiting for the loaded pane. It now waits for actual Activity content. It also preserves its cell model on a no-op resize: the app need not repaint a terminal whose dimensions did not change.
  • An unrelated pre-existing retention test closed the child's stdout pipe after reading its address. A later status print could kill the receiver with BrokenPipe. The fixture now retains the pipe; no retention assertion was removed or weakened.
  • Standalone cockpit owns the collector writer lease. An external CLI grant revocation while that cockpit is open is refused, not a successful live revocation. The local PTY gate therefore proves live expiry, then closes the cockpit, revokes and reopens to prove denial. Live broker revocation remains its separate root-capable isolated test; this host run does not claim it.
  • Broker prompt navigation now shares the local typed page/scope/cursor policy. It no longer falls back to an untyped prompt list or silently relabels a main session with a requested worker identity.
  • The populated harness originally matched denial too early and sent Escape/q without awaiting the return frame. It now waits for exact denial and roster frames. An unavailable main-session key also used to mutate the private reader; it is now inert, with a regression. Both fixes are in 17206a4.
  • Inspected compact expiry frames remove the captured text and show expiry; denial is explicit, and the wide navigator exposes request selection. Repeated status rows and overall visual equivalence are not qualified by these checks.
