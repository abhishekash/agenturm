Trusted synthetic private-reference flow

One fixed fake text source crosses the process wire, host admission, Activity projection, and the generic exact-event reader. No real user content or production capture mode is involved.

Trust boundary

  • A separately installed test child sends only a digest and one coarse event.
  • Host-selected test code reads the configured fixture, verifies source bytes against the lease fingerprint, then commits content with evidence and cursor.
  • The child cannot install or select providers; the host owns the test-only admission and read registries.

Read proof

  • The projection publishes one Activity event, and the generic route resolves only the exact selected event.
  • Output redacts the synthetic password, omits source paths, and stops at 4096 bytes.
  • Revocation and fingerprint reset erase the content; reads remain unavailable after reopening the receiver database.
