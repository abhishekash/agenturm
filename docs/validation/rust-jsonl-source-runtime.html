Shared Rust JSONL source runtime

Recorded 20 November 2026. This refactor extracts the opt-in Pi reader’s bounded file tail, durable cursor, gap generation, complete-line batching, framed handshake, poll/ack sequencing and source-root validation into agenturm-jsonl-source. The Pi-specific parser stays in agenturm-pi-harness behind SourceFormat. The Python receiver owns policy, admission, acknowledgment and every database write.

The trait supplies a pinned plugin ID, gap event prefix, header identity, compact checkpoint and line translation. The runtime admits all facts from one complete JSONL line together or leaves that line unread. Its cursor checks device and inode, offset, preceding bytes and full header digest. Detected replacement, truncation or checked-region rewrite advances the source generation. An invalid checkpoint fails before cursor acknowledgment.

This extraction does not enable another harness, change the default native Pi reader, widen content-free evidence or assert a speed gain. Limits remain one configured file, 1 MiB line and scan caps, 256 records per batch, 8,192 structural tokens and a 512-character cursor. Edits outside the checked region remain an append-only assumption.
