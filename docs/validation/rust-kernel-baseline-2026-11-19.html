Attribution and next target

A separate instrumented 60-batch generated write diagnostic completed 60 writes and 12 read attempts in 6.42 seconds without missed deadlines. Write p50/p95/max was 16.98/45.69/51.96 ms. Total connection time was 1,128 ms; the span insert/trigger path accounted for 643 ms, derived drain 187 ms and commit 110 ms. Intervals overlap and instrumentation changes timing. This tiny fixture suggests SQL and transaction cost but cannot establish production percentages or a Rust-parser speedup.

Synthetic discovery scanned 10,000 files and selected 50 recent sources at 58.891 ms median CPU per scan. Source preparation improved canonical-title and prompt-fallback component medians on a 50-source fixture, but metadata-only and oversized cases did not improve. These component tests do not rank whole-app costs.

Next, profile active native ingestion on a representative retained-history fixture, separating decoding, SQL, derivation, feed and UI work. A Rust slice needs exact semantic parity, measured process/RSS overhead and a same-fixture end-to-end improvement before default activation. The storage-authority cutover retains its separate expert review, parity and rollback gates in the execution plan.
