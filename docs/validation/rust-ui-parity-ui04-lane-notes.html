1 · What changed

Navigator and reader

rust/agenturm-ui/src/workspace/prompt.rs gains the integrated PromptNavigator and refactors PromptScreen onto a reusable PromptBody with a typed PromptPresentation. Added PgUp/PgDn/End, inline drawing, captions and presentation-at-open.

Bounded pages

rust/agenturm-app/src/prompt_history.rs adds a keyset cursor, deterministic newest-first pages, retained-cap disclosure, empty-scope distinction and typed errors over the existing grant-checked list path.

Honest cap

agenturm-store now publishes MAX_PROMPT_REFERENCES = 256, so the UI reports the real retained cap instead of duplicating a private constant.

Architecture. No provider, harness or extension ID is switched on in the UI. Request labels arrive through a typed presentation; the legacy leading-envelope heuristic is confined to the explicitly named compatibility constructor. A capture without adapter normalization is labelled readable form unavailable.

Resize. Navigator ⇄ chooser follows 120 columns. A focused reader stays a reader. An open chooser closes when crossing to wide. The reader keeps the first visible source line, not just the wrapped row, when reflow changes.

Late data. A superseded page token reports Discarded a late prompt response for a superseded view. A stale reader epoch is Late(Superseded); another request is Late(OutOfScope). Rows outside the exact source/session/worker scope are filtered with a visible count.

3 · Wide and compact rendering

Wide

Requests · N loaded index beside Prompt i of N. Before a grant the pane is metadata-only; after a grant the same pane renders the granted body with Request i of N · age.

Compact

One chooser line (Request i of N · label ▾/▴) plus the reader body. The open chooser is a bounded popup — one row per request, at most ten visible, ellipsised by terminal cells — and never displaces the body.

Status line

Loading, loaded count, earlier availability, 256 retained · older history in Activity, empty exact scope, capture disabled, missing identity, denial, revocation, expiry, missing capture, stale source and transport errors each have distinct copy.

Availability states render at 120×32, 80×24 and 60×18. Below the shared terminal floor the module shows Terminal too small · resize · Esc back.

Copy and export

The reference copies the readable or original request and previews an export. Rust keeps the private prompt display no-copy: Ctrl+C remains an interrupt in private/reader focus and c/x are disabled while a granted prompt is visible. This is the existing tighter disclosure policy, recorded as an intentional difference awaiting acceptance (inventory P-09). A future copy must be a grant-aware seam shared with evidence — never a direct text dump.

5 · Retained evidence paging

Prompt history now has an explicit page model, separate from the roster's History time scope:

  • PromptCursor { observed_at_unix_ns, event_id } is an exact keyset, not a row offset.
  • PromptPage reports page rows, retained window size, the adapter cap, whether the cap was reached, and the next older cursor.
  • window() sorts/deduplicates deterministically before slicing, so equal timestamps cannot shift identity.
  • The cap is disclosed as 256 retained · older history in Activity; an empty exact scope is never presented as a complete transcript.
  • Activity/MCP/Traces/Review page identity and filters remain on the existing shell page stack and are untouched.

Honest limit. Until the adapter/kernel exposes a prompt cursor beyond its 256-row window, “earlier” is page-local within the retained window and is labelled that way. Inventory P-10 remains open.

8 · Exact hooks for UI-03 / shell integration

  1. Model fields. Add prompt_nav: Option<prompt::PromptNavigator>, the exact anchor and the read epoch to Workspace. Construct with PromptScope { source, session, worker, turn, capture, main_session }; feed pages only through begin_load/accept_page. Capture policy comes from the source capability, never from an empty list.
  2. Focus. Add Focus::PromptNavigator, PromptChooser, PromptReader. Treat PromptReader exactly as PrivatePrompt: before help/palette, Ctrl+C is an interrupt, F1 does not read the body, Escape clears then returns.
  3. Dispatch. While Prompts is active, route Up Down Home End Enter Right Left Space [ ] l z m Esc to the navigator before global history actions and global navigation.
  4. Return semantics. Read{entry,original,epoch} sends the existing RevealPrompt; on delivery call accept_reader(epoch,(event_id,revision),text,receiver,now) and reuse the active-gate/redraw/ACK path. Back leaves Prompts for the tabs. ReaderClosed just redraws. MainSession(anchor) must re-resolve against the roster. LoadEarlier/Retry reissue the exact-scope page. NoRequests shows status only.
  5. Clear private text. On close/revoke/expiry/back call take_reader/close_reader/revoke/expire, move acknowledge into redact_then_acknowledge, redraw without the body, then ACK — the same contract as dismiss_prompt/expire_prompt.
  6. Render. In draw_workspace_base, render section tabs then navigator.draw(frame,area); use status_line() and hints_for(width). Keep the full-screen reader for non-prompt private content.
  7. Inventory / palette / help. Add prompt.read, prompt.older, prompt.newer, prompt.latest, prompt.presentation, prompt.back, prompt.main-session, prompt.earlier-page, prompt.retry; availability reasons must be explicit. Help shows exact scope, loaded count, cap, expiry and Escape order (chooser → reader → section → roster).
  8. Typed app result. Replace the fact-free WorkResult::Prompts(Vec<PromptEntry>) with entries + retained/cap/earlier/limited + availability, plus a page command carrying anchor and PromptCursor. Map PromptHistoryError 1:1.
  9. Typed presentation. Send { original, readable, hidden_context, truncated } from adapters through the delivery seam and call accept_reader_presentation. This removes the compatibility parser; unknown normalization stays labelled unavailable.

9 · Remaining gaps

Deliberate lane boundary. The navigator is not reachable from the built cockpit until the shared shell adds the fields, focus variants, dispatch arms, render hook and typed app result above. This is not a claim of installed parity.

  • Prompt paging cannot go past the adapter's 256-row window (P-10).
  • WorkResult::Prompts does not yet carry status/page facts, so Tab/Earlier is not user-reachable.
  • Context normalization remains adapter work; legacy deliveries use the compatibility heuristic.
  • Copy/export is the intentional tighter no-copy policy pending acceptance (P-09).
  • Mouse equivalence (P-24) is not implemented; keyboard-only acceptance is the current candidate.
  • The integrated PTY journey was not run because the shared render/dispatch hook is absent in this branch; component tests and real content/investigation fixtures were run.
  • Idle investigation policy invalidation (P-18) is partial: a changed source is refused on the next read, not proactively cleared.
  • Activity/MCP/Traces/Review page identity remains shell/UI-05 ownership and was not changed.

10 · Pluggable-seam implications

Adapters stay authoritative

The navigator consumes typed request metadata and presentation facts; it never parses harness files or provider envelopes. The one compatibility parser is named and isolated.

Grants stay in the app

Listing, cursor proof and reveal remain in agenturm-content. The UI carries event/revision/snapshot/history identity back to the app; revocation and expiry clear the body before ACK.

Missing facts are labelled

Readable form unavailable, metadata only, capture disabled and prompt history unavailable are explicit states. Nothing is guessed from silence or an empty list.

No seam bypass

Nothing here bypasses kernel ports, supervised adapters, ExtensionPlugin/capability/pane seams or the process-plugin host. The navigator is a generic evidence view over host-supplied facts.
