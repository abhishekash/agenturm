Inert plugin manifest checkpoint

observatory/plugin_manifest.py reads only explicitly supplied TOML paths. It caps each file at 64 KiB and validates plugin IDs, versions, protocol ranges, entrypoint arguments, artifact hashes, features, dependencies and grants. Discovery does not import or execute plugin code.

Activation planning

Given an explicit enabled set, host features and allowed grants, the resolver rejects missing or disabled dependencies, incompatible protocols, denied grants, absent or ambiguous feature providers and cycles. It returns a deterministic order; it starts no process. Multiple providers require an explicit dependency choice.

Current boundary

This is an internal preliminary schema. Artifact verification at launch, configuration schemas, installation and upgrades, process supervision, activation leases, durable cursor acknowledgements and extension conformance remain later work. The validator is not a sandbox or an authentication guarantee. The Python Store remains the only writer.
